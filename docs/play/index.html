Java Edition

Для компьютера с Minecraft Java.

Адрес сервераarhalcanpagari.kvadrober.cc
Адрес с портом
Резервный адрес95.216.30.27:25806
  1. Войди в Minecraft под своей учётной записью Microsoft.
  2. Открой «Сетевая игра» → «Добавить сервер».
  3. Введи OLYMP и адрес, сохрани и выбери «Подключиться».

Сервер работает на Paper 26.3. Список совместимых клиентов пока не опубликован.

Bedrock Edition

Для iPhone, iPad, Android и Windows с Bedrock.

Адрес сервера95.216.30.27
Порт25639
  1. Открой «Играть» → «Серверы».
  2. Нажми «Добавить сервер» и укажи имя OLYMP.
  3. Вставь адрес и порт в отдельные поля. Сохрани и нажми «Играть».

Точная версия клиента для текущей сборки уточняется в теме помощи.
