Конфиденциальность

Редакция от 21 ноября 2026 года.

Здесь описано, какие данные нужны, чтобы открыть страницы OLYMP, посмотреть онлайн и перейти в сообщество. Раздел относится к сайту. У игрового сервера и Telegram свои процессы обработки данных.

Просмотр страниц

Сайт работает без регистрации. Для просмотра страниц не нужны игровой пароль, телефон или дата рождения. На сайте нет оплаты, рекламных трекеров и форм загрузки файлов.

Данные подключения

Сайт размещён на GitHub Pages. При открытии страниц GitHub получает технические данные запроса, в том числе IP-адрес. Они используются для доставки страниц, безопасности и диагностики. Срок хранения определяется правилами поставщика. Политика конфиденциальности GitHub

Мониторинг

Для показа онлайна браузер обращается к публичному сервису mcstatus.io. Сервис получает IP-адрес посетителя, как при открытии любой страницы, и публичный адрес игрового сервера. Сайт показывает только число игроков, время и результат проверки.

Хранение в браузере

В коде сайта нет рекламных cookies и средств отслеживания посетителей. Браузер может временно сохранять страницы, стили и изображения для ускорения загрузки. Срок хранения зависит от заголовков ответа и настроек браузера.

Переход в Telegram

Ссылка на сообщество открывает Telegram по вашему выбору. Там действуют условия Telegram. Сообщения в публичной группе доступны другим людям. Документы, пароли и личные данные в общий чат отправлять не следует. Политика Telegram

Как задать вопрос о данных

В закреплённой навигации Olymp | Mine выберите «Написать владельцу». Опишите вопрос в личном сообщении и укажите, что он относится к сайту. Достаточно адреса страницы и примерного времени посещения. Не публикуйте запрос с личными данными в общей теме. Открыть навигацию сообщества

За содержание отвечает команда OLYMP. Подтверждённые сведения об операторе и прямой канал для запросов о персональных данных пока не опубликованы. До их добавления этот раздел носит справочный характер.
