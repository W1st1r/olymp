# OLYMP
Публичный сайт проекта. Страницы GitHub Pages публикуются из папки docs ветки main.
Измените config.json для адресов сервера, Telegram и режима доступа, view.mjs для текста, privacy.json для политики. Изображения находятся в docs/media.
Запустите `node build.mjs` (Node.js 22+) и сохраните исходники и изменившиеся файлы docs одним коммитом. Для отката отмените коммит с изменением.
Мониторинг использует публичный API mcstatus.io с кешем провайдера. Браузер запрашивает состояние раз в минуту, пока вкладка видима. Время проверки берётся из ответа источника.
